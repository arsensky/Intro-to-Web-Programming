# Intro-to-Web-Programming course (COM - 388.1)
This repository contains materials for the **Introduction to Web Programming** course (COM-388.1), Spring 2026.

## Course Overview
The course introduces the fundamentals of web development, including basics of:
- HTML
- CSS
- Java Script
- Python
- Database (PostgreSQL)

All required labs and other study materials are organized into separate folders/repositories.

## Labs
- All **Labs (1–52)** are completed.
- Labs are located in the `Labs/` directory.
- **Lab 1** and **Lab 2** cover Python and PyCharm installation. They are instructional, so no separate folders were created.
- All other labs contain practical implementations and are organized accordingly.

### Pet Project
**"Task Manager"** Pet Project from Lab materials is located in the `Task_Manager/` directory.
